รูปถ่าย

เกี่ยวกับวิชา Full Stack Web Development

เหตุผลที่อยากเรียน Full Stack Web Development

ต้องการเข้าใจกระบวนการพัฒนาเว็บไซต์ทั้งส่วน Frontend และ Backend เพื่อให้สามารถสร้างเว็บไซต์ที่ทำงานได้จริงตั้งแต่ต้นจนจบ

ความคาดหวังต่อวิชานี้

คาดหวังว่าจะได้เรียนรู้พื้นฐานที่ถูกต้อง และสามารถต่อยอดไปทำโปรเจกต์ของตัวเองเพื่อใช้ใส่พอร์ตโฟลิโอได้

จุดอ่อนที่ต้องพัฒนาเกี่ยวกับทักษะ Programming และแนวทางการพัฒนา

จุดอ่อนคือการคิดแก้อัลกอริทึมที่ซับซ้อน แนวทางแก้ไขคือการหมั่นฝึกเขียนโค้ดและทำโจทย์อย่างสม่ำเสมอ
